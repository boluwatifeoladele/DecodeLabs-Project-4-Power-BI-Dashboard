# DecodeLabs Project 4: Power BI Dashboard

## Project Overview
This project involves building an interactive Power BI dashboard to explore and analyse order data. The dashboard presents key information through visualisations that make it easier to understand product performance, order status distribution, and monthly order trends.

## Tools Used
- Microsoft Power BI
- Data visualisation and dashboard design

## Dashboard Features
- **Order Count by Product:** Compares the number of orders across different products.
- **Total Sales by Product:** Compares total sales generated by each product.
- **Order Status Distribution:** Shows the distribution of orders across different statuses.
- **Monthly Order Trend:** Visualises changes in order activity over time.

## Key Skills Demonstrated
- Data visualisation
- Interactive dashboard development
- Trend analysis
- Presenting data insights clearly

The Power BI report (`.pbix`) is included in this repository.
